Nine diagram types, one colour system

24px dots (default). Neutral boxes · grouping hues on loops, branches and periods only · one pink focal element · status colours only where literal.

Flowchart

Architecture with three groups and a focal box. The path that is deliberately not used is neutral and dashed, not red: it is not a risk.

Sequence

The par block is a group; the note is a margin note; the Worker is focal.

State

The composite state is a group; Degraded uses status orange because it literally is a warning state.

Entity relationship

Entities are neutral; one focal entity.

Git graph

Branches are groups: main stays neutral, feature branches take grouping hues in order. Labels are outlined pills.

Timeline

Periods are ordered steps, not groups, so they stay neutral; the step the text is about is focal.

Architecture

Groups as loops, services neutral, one focal service.

Bar chart

Bars are neutral; the one bar the text talks about is focal.

Mindmap

Neutral, with one focal branch: a mindmap is a breakdown, not a set of containers.

Vocabulary

Every shape and line once, each line showing its own meaning. No single subject, so no colour.
