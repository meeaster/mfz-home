# Cairn design context

This folder preserves the human's intent for Cairn, design reasoning, and the real situations its workflows must support. Design context can include unresolved proposals; current implementation is established by source and maintained usage documentation.

- `scenarios/` describes situations the human encounters, the understanding they need to preserve, and observable outcomes. Use relevant scenarios when proposing workflow changes or selecting evaluations.
- Read only the material relevant to the current question. Scenario maintenance guidance lives in `scenarios/AGENTS.md`.
