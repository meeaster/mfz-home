# Cairn workflow scenarios

These scenarios describe real situations the human encounters while working with agents. They give design discussions and evaluations concrete needs to test against.

| Scenario | Main question |
| --- | --- |
| [Observability pipeline](observability-pipeline.md) | How does work remain understandable as its scope grows, dependencies emerge, and decisions arrive through different people and systems? |
| [Related work with separate contexts](related-work-with-separate-contexts.md) | How can related deliverables continue in fresh sessions with focused context while preserving shared intent and reasoning? |

Read the scenario relevant to the question at hand. Each is a detailed, self-contained account of the situation, the human's needs, and observable success. Illustrative examples and unresolved choices are identified in the text. Current implementation analysis belongs in separate design or evaluation documents, which can refer to these scenarios.
