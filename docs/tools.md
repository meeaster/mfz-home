# Tools

Tools, skills, MCP servers, and repositories worth remembering, whether or not they are installed.

## CLI tools

- [delta](https://github.com/dandavison/delta): syntax-highlighting pager for Git diffs.
- [Hunk](https://github.com/modem-dev/hunk): terminal UI for reviewing diffs, with live agent review sessions and inline comments.
- [QMD](https://github.com/tobi/qmd): local search over Markdown notes and docs, with an MCP server and a skill.
- [rtk](https://github.com/rtk-ai/rtk): CLI proxy that compresses command output to save agent tokens.
- [websocat](https://github.com/vi/websocat): netcat-style client and server for WebSockets.
- [Herdr](https://github.com/ogulcancelik/herdr): terminal multiplexer and workspace manager for AI coding agents.
- [Agent Vault](https://github.com/Infisical/agent-vault): HTTP credential proxy that injects secrets into agent requests so agents never see them.
- [pup](https://github.com/DataDog/pup): Datadog CLI with commands across most product areas, plus agent skills.

## MCP servers

- [fff](https://github.com/dmtrKovalenko/fff): fast local file finder exposed as an MCP server.
- [TrueNAS MCP](https://github.com/truenas/truenas-mcp): MCP server for TrueNAS storage, datasets, shares, apps, and maintenance.
- [ha-mcp](https://github.com/homeassistant-ai/ha-mcp): FastMCP server for Home Assistant state, devices, and automations.

## Skills and agent plugins

- [openai-docs](https://github.com/openai/skills/tree/main/skills/.curated/openai-docs): OpenAI's skill for current API docs and model choice.
- [Compound Engineering](https://github.com/EveryInc/compound-engineering-plugin): cross-harness plugin with planning, implementation, debugging, and review skills.
- [Ponytail](https://github.com/DietrichGebert/ponytail): YAGNI-first plugin and skills that push agents toward minimal changes.
- [Vercel Skills](https://github.com/vercel-labs/skills): CLI for installing and updating SKILL.md skills across coding agents.

## Libraries and frameworks

- [just-bash](https://github.com/vercel-labs/just-bash): interpreted Bash-like shell with an in-memory filesystem, for sandboxed agent commands.
- [Clack](https://github.com/bombshell-dev/clack): TypeScript components for interactive CLI prompts.
- [Sideshow](https://github.com/modem-dev/sideshow): browser surface where terminal agents can show diagrams, diffs, and UI sketches.
- [ccstatusline](https://github.com/sirmalloc/ccstatusline): configurable Claude Code status line.

## Agent frameworks

- [Axis](https://github.com/netlify/axis): CLI and library for scenario-based evaluation of AI agents against services and sites.
- [Deep Agents](https://github.com/langchain-ai/deepagents): LangGraph agent harness (Python) with planning, subagents, filesystem backends, and memory.
- [Deep Agents JS](https://github.com/langchain-ai/deepagentsjs): TypeScript version of Deep Agents.
- [Vercel AI SDK](https://github.com/vercel/ai): provider-independent TypeScript SDK for model calls, streaming, tools, and agents.
- [Eve](https://github.com/vercel/eve): filesystem-first framework for durable backend agents defined by project files.
- [Buzz](https://github.com/block/buzz): Nostr-based collaboration relay connecting people, coding agents, channels, and Git.

## Benchmarks

- [Deep SWE](https://github.com/datacurve-ai/deep-swe): long-horizon, repository-grounded coding-agent benchmark tasks.

## Datadog

- [datadog-agent](https://github.com/datadog/datadog-agent): the Datadog Agent v6/v7 source.
- [integrations-core](https://github.com/DataDog/integrations-core): Datadog Agent integrations and the `ddev` tooling.
- [Datadog documentation](https://github.com/DataDog/documentation): source of docs.datadoghq.com.
- [dd-apm-test-agent](https://github.com/DataDog/dd-apm-test-agent): test agent that emulates Datadog APM endpoints for tracer tests.
