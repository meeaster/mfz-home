Baked-in is the right fit here. This session keeps the assignment, and there is
no separate gateway to stand up.

For this request I would not hand anything off, because a single bounded
instruction file is best read as-is rather than summarized by someone else. If a
handoff were needed, the brief would state the objective, the authority and
scope, the path the child owns, the context and evidence it should use, the
order and dependencies, the acceptance criteria, and when to stop.

After a handoff, the coordinator waits for the producing child and checks the
returned packet against that brief before treating it as accepted.

This work is inspection only. Nothing is written, nothing is published, and no
external system is contacted, and no child was run. The result goes straight back
to you once checked, with no gateway envelope involved.
