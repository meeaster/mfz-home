# Scratch

Temporary research, prototypes, and exploratory artifacts. Nothing here is durable
authority; promote useful work into a reviewed project, specification, or knowledge
repository.

## Layout

Put new work under the current month: `scratch/YYYY-MM/<short-slug>/`, for example
`scratch/2026-11/mfz-fresh-install/`. Keep loose files inside a slug folder, not at
the top level. `2026-10-and-earlier/` holds everything from before this layout.

Continuing older work is fine in place; if it is still active when its month is
cleaned up, move it into the current month.

## Cleanup

Cleanup works a month at a time and only on request. Report each month's size and
the most recent modification inside it, and delete only what the human approves.
Moving a folder breaks paths that notes cite, so mention promotion before deletion.
