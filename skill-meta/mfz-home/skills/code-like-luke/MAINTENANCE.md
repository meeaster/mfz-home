# Maintenance

## Dependencies

The runtime skill has no scripts, external tools, or required references. Its body is intentionally preserved from the former OpenCode command.

## Change Procedure

1. Preserve the runtime body unless the user explicitly requests a guidance change.
2. Update the catalog description if the explicit invocation contract changes.
3. Keep the authoring record aligned with the runtime package.
4. Verify the skill package and compare the runtime body with the former command history when investigating drift.

## Verification

Confirm valid front matter, catalog registration, user-invoked behavior, and exact preservation of the transferred guidance.
