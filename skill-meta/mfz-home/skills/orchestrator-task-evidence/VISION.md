# Vision

The human requested one lightweight, explicitly loaded shared skill for reusable task evidence. It removes note methodology from Orchestrator Mode without duplicating that method in agent system prompts. The intended consumers are assigned producers and downstream readers in this OpenCode V2 home, with access to the same temporary evidence root.

The parent must name the skill ID and supply the concrete objective, authority, exact owned path when writing, required sources and relevant evidence paths, acceptance criteria, and stop conditions. Neither discovery, permission, nor a skill load creates work or authorizes files. Every evidence-producing orchestration dispatch receives a file assignment, even for a small finding, because later reuse cannot reliably be predicted. Ordinary exploration outside orchestration remains file-free.

Producer-owned coherent notes preserve source attribution, applicability, exact consequential details, freshness, and useful execution lessons without transcripts or quotas. Their modest recognizable structure helps reuse without forcing a section inventory; readers choose whether to read a whole note, search it, or use selected sections. Completed-note handoffs and serialized updates prevent partial downstream reads. Genuine writing conflicts retain the coordinator-owned attributed fallback. Shared-root permission is not per-producer isolation, and temporary evidence is not durable knowledge.

One producer file may hold multiple useful findings. The human values enough exact evidence to avoid guessing or repeated investigation, not a retained inventory or a section for every consideration. Later producers should contribute new evidence or judgment while referencing applicable earlier findings. Supporting detail remains conditional, with no fixed template or word cap.

Orchestrator Mode retains when a workspace is warranted, placement, context/design/index ownership, coordination, nesting, and depth limits. After the first dispatched producer note is complete and checked, its concise index catalogs completed notes for recovery and discovery without becoming a pre-dispatch manifest, reading prescription, or second evidence body. Agent definitions retain only the narrow requested-write allowance. Worker and operator work authority remains unchanged.
