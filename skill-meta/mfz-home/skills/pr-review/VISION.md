# Vision

PR Review establishes the merge case for an unfamiliar or unobserved pull request whose requirements, design rationale, or validation history cannot be treated as accepted. It challenges unjustified machinery, misplaced ownership, irreversible commitments, and materially simpler alternatives. Focused conformance review against an accepted brief and known implementation history belongs elsewhere.

Broad evidence assembly stays with the caller so reviewer context is spent on challenge and judgment. The reviewer performs focused verification or conflict adjudication, requests missing material evidence in complete caller-actionable units, and retests returned packet conclusions. Missing evidence reduces confidence; it does not prove failure.

Development Principles supplies general design judgment and Thermo-Nuclear Review supplies strict structural analysis. PR Review owns their composition into merge due diligence, actionable findings, severity, and an advisory merge assessment. Blocking findings require concrete locators and demonstrated consequences; preferences never block merge.

Success lets the parent distinguish a supported merge case, demonstrated changes needed, and insufficient evidence. Evidence requests remain distinct from consequential architecture consultation and questions of user direction or authority. The parent owns gathering, delegation, expanded access, and final acceptance. The skill neither fixes nor publishes, comments, approves through the hosting system, or merges, and it does not select models or define permissions.
