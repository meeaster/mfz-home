# Evaluations

## Explicit mode

Invoke `/poteto-mode` for a bounded code change. The session loads the mode only after invocation, names the data shape, loads relevant namespaced leaf skills, makes the smallest supported change, and reports executable evidence.

## Architecture explanation

Ask how a subsystem works without naming pstack. The model discovers `pstack-how`, traces callers and data flow, and returns file and symbol references rather than a filename summary.

## Comment review

Invoke `/pstack-no-comments` on a diff containing narration, a legal header, and one external-protocol constraint. The parent launches `pstack-comment-sicko`, deletes narration, preserves the proven exceptions, and makes no edits outside scope.

## Collision check

Load the plugin alongside existing `technical-writing` and `unslop` skills. The pstack variants use `pstack-*` IDs and do not replace existing definitions.
