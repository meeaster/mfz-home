# Vision

Provide pstack's useful engineering workflows to OpenCode through native skills and subagents. Skills remain the product. The plugin only registers packaged assets and adapts provider mechanics.

This is a local Personal Mindframe-Z plugin, not a separately published package or a standalone skill despite this record's directory placement. Namespaced `pstack-*` skills coexist with the existing Personal writing and engineering skills. Poteto mode and comment cleanup remain explicitly invoked; architecture explanations can discover the relevant leaf skill. Host instructions and user authority control delegation and edits.

The initial package favors portable principles and a small coherent workflow over a literal Cursor port. Runtime hooks, TUI features, model routing, automations, and polling belong in later changes only when an OpenCode use case proves they are needed.
