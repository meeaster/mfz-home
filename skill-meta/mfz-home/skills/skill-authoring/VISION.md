# Vision

Help users turn intended agent behavior into skills and explicit commands that are economical to load and useful in execution. Preserve human intent separately from implementation so later revisions do not silently redefine success.

## Priorities

- Begin with intended behavior and concrete uses. Let those determine the artifact's form.
- Spend context where it can affect the current decision or verification. Stored material needs durable value; loading it also needs task relevance.
- Preserve concise intent and discriminating evaluation scenarios by default. Optional records must earn their existence through provenance, non-obvious upkeep, or consequential rationale. Document completeness is not the outcome.
- Distinguish expected behavior from observed evidence. Use real artifacts and traces when claiming execution quality.
- Keep assessment non-mutating unless implementation is authorized. Ask about consequential changes to human intent; do not promote agent choices into requirements.
- Keep the core portable. The environment owns installation, harness operation, and workspace paths.

Skill Authoring remains user-invoked. Runtime writing quality belongs to Writing for Agents; the bundled planning adaptation supplies complementary resource and fragility guidance. One unambiguous authoring record preserves development knowledge outside ordinary skill execution.

Success means a future author can understand the purpose, make a relevant change, and check its behavior without reading the full authoring history. The process must work for both tiny skills and consequential workflows without filling unused documents.
