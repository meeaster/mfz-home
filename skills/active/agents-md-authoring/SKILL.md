# AGENTS.md authoring

## Establish scope

- Match the work to the request. For "record this," preserve the established meaning and inspect the target plus applicable ancestor instructions. Reserve broader investigation for creating or reassessing repository-wide guidance. A review returns recommendations unless edits are requested.
- Put guidance at the narrowest scope that serves its consumers. Parent files carry shared orientation and rules; folder-local files carry specialized maintenance guidance. Check inheritance and avoid repeating it. Verify harness loading behavior only when placement depends on it.
- Ask about an unresolved convention or intent only when the answer changes the guidance and existing context cannot supply it.

## Select useful content

- For each passage, ask: "Would an agent likely miss this without help?" Keep deliberate human preferences, non-obvious ownership, workflow constraints, and consequential corrections. Omit generic advice and explanations of familiar AGENTS.md mechanics.
- Ground implementation facts in relevant source. For repository setup, inspect manifests, task and verification configuration, CI, and existing instructions before representative code. Look for command prerequisites, focused checks, generated-file boundaries, and operational quirks. Resolve conflicts using executable sources for current behavior while preserving separately stated human intent.
- Prefer facts that required interpretation over inventories available from a directory listing. Include exact commands when they prevent likely mistakes; avoid duplicating readily discoverable configuration without a concrete benefit.

## Integrate and prune

- Improve existing sections rather than append a rule by default. Reconcile overlap and conflicts, preserve useful guidance, and remove verified stale claims within the requested scope.
- Use short topic sections and clear bullets without a mandatory template. Keep conditions and exceptions beside the behavior they qualify. Include rationale when it changes how the instruction should be applied.
- Keep automatically loaded instructions economical. Put substantial reference material behind a pointer with a clear reading condition; selective reference documents can remain detailed. Do not turn AGENTS.md into a transcript, tutorial, or exhaustive file tree.
- Before finishing, check that each addition changes a useful decision, preserves the human's meaning and authority, and fits its scope without duplication. Verify changed paths and commands against source; run commands only when validation requires their execution. Report the edit or review findings and unresolved uncertainty.
