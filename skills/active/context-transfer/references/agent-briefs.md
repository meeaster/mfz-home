# Agent Briefs

When dispatching a fresh agent to research, plan, review, or implement work, write an intent-rich task brief. Preserve the user's decision criteria, not only the requested deliverable.

- State the objective, intended outcome, and why the outcome matters.
- Carry the user's relevant priorities, concerns, themes, and tradeoffs when they affect a downstream judgment. Distill spoken-style repetition into clear direction; do not discard it merely because it was not phrased as a task.
- Name settled facts, source-of-truth constraints, exclusions, accessible evidence, authority limits, deliverable, verification, and stop conditions.
- State the freedom boundary: describe the desired result and constraints first; prescribe a method only when repeatability, safety, or a settled decision makes that method consequential.

Do not transcribe the source conversation. Carry its decision-relevant meaning in a structure the receiving agent can use without guessing the user's intent.

Done when a fresh agent can make aligned judgments from the brief without reconstructing the user's goals, rationale, or authority boundary.
