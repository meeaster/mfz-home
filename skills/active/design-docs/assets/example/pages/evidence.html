Everything we've found out about log ingestion, and how we know it. Every page of this doc cites these by number.

E1
Firewall logs from all 14 sites reach the syslog server over site VPNs that end on the Transit Gateway. The VPNs only carry routes for 10.40.0.0/16.

How we know

Read the Transit Gateway route tables in the network account and matched them against the VPN module in the network Terraform. Both show the site VPNs advertising only 10.40.0.0/16. The network team confirmed it's current.

Gathered from

AWS accountprod-network · Transit Gateway route tables
Infrastructure as codeinfra-network repo · VPN module
Confirmed withNetwork team, Sep 24

How we know
