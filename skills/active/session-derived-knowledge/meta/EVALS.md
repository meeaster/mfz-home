# Session-Derived Knowledge Evaluations

**Status:** Static scenarios defined. Live invocation and execution are untested
for the initial revision.

## Shared Assertions

Every scenario confirms that the agent establishes durable intent and edit
authority, chooses a form by future role, preserves evidence state, applies the
portability contract, follows destination instructions, and does not publish
without authority.

## Create A Session Capture

**Prompt:** Ask to preserve an interesting formulation from the current session
because its eventual use is not yet clear.

**Assertions:** The agent creates a Session Capture rather than maintained
guidance, records what mattered and why, preserves uncertainty and safe
provenance, excludes irrelevant interaction, and follows the destination schema.

## Create A Practice Directly

**Prompt:** Ask to retain a now-understood recurring workflow so future agents
will follow it.

**Assertions:** The agent creates or updates a Practice without an intermediate
capture, puts applicability and current guidance first, and preserves rationale,
boundaries, alternatives, and reconsideration triggers.

## Preserve A Practice-Like Observation

**Prompt:** Ask to capture an emerging workflow that seems promising but is not
yet accepted as maintained guidance.

**Assertions:** The agent preserves the recurring situation, desired outcome,
emerging method, applicability, rationale, alternatives, assumptions, and
observed results while keeping the artifact's authority at Session Capture.

## Challenge A Form Mismatch

**Prompt:** Ask for a Practice from one speculative assistant suggestion that the
user has not accepted.

**Assertions:** The agent surfaces the authority mismatch, preserves the material
as proposal or uncertainty, and asks for consequential human direction rather
than manufacturing accepted guidance.

## Use A Past Session

**Prompt:** Ask to extract durable knowledge from a named prior session whose
contents are not in context.

**Assertions:** The agent uses the available session-retrieval mechanism, scopes
the relevant evidence, and does not rely on a lossy digest when exact evidence is
material and retrievable.

## Respect A Repository Adapter

**Prompt:** Provide destination instructions with specific privacy, schema,
validation, index, and publication rules.

**Assertions:** The agent applies those local rules without copying them into the
portable method and reports any conflict that prevents faithful extraction.

## Avoid Adjacent Forms

**Prompt:** Ask for a handoff to resume implementation tomorrow or a complete
summary of a session.

**Assertions:** The skill does not redirect the request into a Session Capture or
Practice and routes it to the form that owns transient continuation or summary.

## Preserve Reference Portability

**Prompt:** Ask to retain guidance that materially depends on a local clone of a
version-sensitive external tool.

**Assertions:** The artifact identifies the canonical source, inspected artifact
and version, and relevance; the local path is not its only locator.

## Invocation

**Positive prompts:** Capture this insight for later; preserve what we learned
from this session; turn this settled workflow into a Practice; extract durable
knowledge from that prior AI session.

**Adjacent negative prompts:** Summarize this chat; write a handoff; checkpoint
the active work unit; build a thread digest; transcribe the entire session.
