# Log

## 2026-08-05 - Initial Design

- Chose model invocation because explicit requests to preserve session knowledge
  should reach the workflow without requiring the user to remember a command.
- Made durable preservation explicit rather than automatic; ordinary summaries,
  handoffs, threads, and work-context checkpoints remain separate forms.
- Kept Session Capture and Practice as portable semantic roles while delegating
  their concrete storage and publication contracts to destination instructions.
- Defined Capture and Practice as direct alternatives so settled guidance does
  not pass through a mandatory capture lifecycle.
- Preserved evidence state, uncertainty, and human authority as part of the
  extraction rather than relying on polished prose to imply correctness.
- Moved the shared portability contract into the runtime skill without personal
  paths, private systems, or harness-specific mechanics.

## 2026-08-05 - Separate Context Transfer

- Replaced maximum generic portability with a session-independence floor: normal
  use cannot require the source session, hidden conversation, or one harness.
- Moved consumer, destination, intentional-dependency, detail, and proportional-
  reference decisions to the model-invoked `context-transfer` skill.
- Preserved intentional local dependencies when the transfer contract guarantees
  them rather than forcing every Capture or Practice to be globally standalone.
- Kept the original session as an optional audit or attribution escalation path,
  not a normal continuation dependency.
