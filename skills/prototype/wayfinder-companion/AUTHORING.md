# wayfinder-companion

## Intent

Keep durable human direction, current thinking, evidence, and a working model beside a Wayfinder map across a long effort, without building a competing planning system. Wayfinder's map stays the only planning index and its tickets keep decision authority.

Not for: transcript archives, status boards, implementation plans, or empty placeholder artifacts.

Success: a later session can resume one decision from the map and the relevant context without reconstructing earlier exploration.

## Scenarios

- **New context-heavy effort**: Wayfinder first; companion artifacts only after the map exists in an authorized location, linked from it.
- **Local Markdown map**: `working-model.md` first; `research/` and `experiments/` only when their first record is needed.
- **Research then a prototype that changes the model**: source findings in research records, prototype learning in an experiment readout; prototype source stays in its own repository.
- **The human wants product purpose and principles to survive**: a concise human-owned vision linked from the map, kept apart from the planning destination.
- **The human's leanings and concerns should carry across sessions**: `current-thinking.md`, rewritten in place, with meaningful shifts in `thinking-log.md`.
- **Evidence contradicts the vision**: the working model updates; the vision changes only after the human accepts it.
- **Prepare a design fork for other people**: a brief under `decision-briefs/` for an existing grilling ticket; no participant or approval management. Not created unless asked.
- **Closing research, prototype, and out-of-scope tickets**: one linked gist each under decisions so far; out-of-scope only under out of scope.

## Decisions

- **User-invoked, with a manual handshake** (2026-08-02). Starting or continuing a large planning effort is deliberate, and Wayfinder is user-invoked too; the companion must never imply it can run Wayfinder itself.
- **Track the human's vision** (human, 2026-08-02). The human asked whether Wayfinder tracked their vision for the feature; it didn't, so vision became the companion's durable-direction artifact, separate from the map's destination.
- **Optional adjacent artifacts, not an evidence pack** (2026-08-03). A wrapper would become a second orientation index next to the map.
- **Current thinking separate from recommendations and decisions** (2026-08-05), so agents can recover the human's live stance without mistaking it for an accepted decision.
- **No assumed location, tracker, or layout**; the active effort decides where artifacts live.
- **Parked as a prototype** (human, 2026-09-14): created but not actively used.

## Sources

None external. Wayfinder owns the map, ticket, and resolution contracts; recheck the handshake, local Markdown conventions, closed-ticket indexing, and prototype-ticket behavior when Wayfinder changes.
